# 🚀 AI Business Intelligence Copilot

An AI-powered Business Intelligence Dashboard built using Streamlit, Python, Plotly, and Machine Learning.

This project helps businesses analyze sales, profit, customer trends, forecasting, and generate AI-driven insights interactively.

---

# 📌 Features

## 📊 Interactive Dashboard
- KPI Cards
- Sales Analytics
- Profit Analytics
- Monthly Trends
- Top Sub-Categories

## 🎯 Smart Filters
- Region Filter
- Category Filter

## 🤖 AI Business Insights
- Highest Sales Category
- Most Profitable Region
- Monthly Growth Insights

## 💬 Chat With Your Data
Ask questions like:
- Total Sales
- Total Profit
- Top Category
- Top Region
- Highest Sales Month

## 🔮 Sales Forecasting
- Predict next 6 months sales
- Machine Learning forecasting using Linear Regression

## 📥 Download Reports
- Export filtered data as CSV
